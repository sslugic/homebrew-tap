# Homebrew tap

```bash
brew trust sslugic/tap
brew install --cask sslugic/tap/undertone
```

Homebrew 7 asks you to trust a tap once before installing from it.

[Undertone](https://getundertone.app/) explains jargon during your calls and reminds you of the facts when you're asked. macOS 26 or later. The app updates itself after install.
